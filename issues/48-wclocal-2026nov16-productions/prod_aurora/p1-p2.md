### Pitfall found in the first try (fixed)

The first P1 run (try 1, kept in `p1/try1/` on Flare) differed from issue 47 in 16 `T_tagger.*_score` branches in all 67 files.

- `UbooneNueBDTScorer` then only WARNs ("weight file not found … skipping nue BDT scoring"); the job still ends rc 0.
- **Fix:** I copied the file into `$Y/wcd-0.38.0` (sha256 `6199d202…`, identical).
- **Guard:** `step2.sh` on `wclocal-nov16` (`d05cf47`) now counts these lines into `weights_fail` and exits **rc 91** if any are found.
